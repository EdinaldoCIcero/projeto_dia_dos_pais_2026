# 💌 Homenagem Especial - Dia dos Pais

Uma aplicação web interativa, moderna e emocionante desenvolvida para celebrar o Dia dos Pais. O projeto conta com um design limpo utilizando o conceito de *Glassmorphism*, animações fluidas, trilha sonora automatizada, carrossel de fotos interativo com modal em tela cheia e links diretos para engajamento.

---

## ✨ Funcionalidades

* **Envelope Interativo (Tela Inicial):** Uma carta de boas-vindas com efeito de abertura por toque, que ajuda a burlar as políticas de autoplay de áudio dos navegadores de forma elegante.
* **Trilha Sonora de Fundo:** Player de áudio integrado que inicia junto com a abertura da homenagem e conta com opção de pause/play.
* **Carrossel de Fotos Moderno:** Slider horizontal fluído para navegar pelos melhores momentos da família.
* **Modal em Tela Cheia:** Ao clicar em qualquer foto do carrossel, ela se expande em alta resolução.
* **Vídeo de Fundo Dinâmico:** Fundo cinematográfico imersivo.
* **Mural da Família:** Seção dedicada para recados e mensagens carinhosas.
* **Call to Action (CTA):** Botão personalizado integrado ao Instagram para captação de clientes ou compartilhamento.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias web modernas, sem dependências complexas (Vanilla Stack):

* **HTML5** (Estruturação semântica)
* **CSS3** (Flexbox, Grid, Animações e *Glassmorphism*)
* **JavaScript Moderno (ES6+)** (Manipulação de DOM, requisições assíncronas e controle de mídia)
* **FontAwesome** (Ícones)
* **Google Fonts** (Tipografia - *Outfit*)
